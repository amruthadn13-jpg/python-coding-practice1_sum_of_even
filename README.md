# python-coding-practice1_sum_of_even

##  Problem 1 – Sum of Even Numbers

### Problem Statement
Write a Python program that takes a list of integers from the user and
prints the sum of all even numbers in the list.

### Example Input
1 2 4 6 9 12 5

### Output

24

### Solution Description
The program reads a line of numbers from the user, converts them into a
list of integers and checks each number using a loop.
If the number is even, it is added to a total variable.
Finally, the total sum of even numbers is printed.
